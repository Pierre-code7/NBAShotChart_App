# NBAShotChart_App

## Description
NBAShotChart_App is a powerful tool for visualizing and analyzing NBA player shooting data. This application allows users to generate detailed shot charts for NBA players, providing insights into shooting patterns, efficiency, and tendencies across different areas of the court.

## Features
- Generate shot charts for any NBA player
- Visualize shooting percentages by court location
- Compare multiple players' shot charts
- Filter data by season, game type (regular season/playoffs), and more
- Export charts as high-quality images
- Interactive Shot Visualization point by point

## Installation
To set up the NBAShotChart_App locally, follow these steps:

1. Clone the repository:
Apply
   git clone https://github.com/Pierre-code7/NBAShotChart_App.git
2. Navigate to the project directory:
   cd NBAShotChart_App
3. Install the required dependencies:
   pip install -r requirements.txt

## Usage
To run the application:

1. Start the app:
   python main.py
2. Open your web browser and go to `http://localhost:5000`
3. Follow the on-screen instructions to generate shot charts
